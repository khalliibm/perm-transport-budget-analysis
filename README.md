# Неравномерная транспортная доступность в Перми

## Обзор

Проект посвящен анализу общественного транспорта Перми и разработке решения для повышения транспортной доступности удалённых микрорайонов.

Основная проблема заключается не в общем количестве маршрутов, а в их неравномерном распределении и низкой устойчивости транспортного сообщения в отдельных районах.

## Цель

Разработать финансово реализуемый сценарий улучшения транспортной доступности без увеличения дефицита муниципального бюджета.

## Решение

В проекте были рассмотрены два варианта:

- закупка муниципальных автобусов
- финансирование дополнительных рейсов через брутто-контракты

В качестве итогового решения выбран смешанный сценарий:

- закупка 12 автобусов
- финансирование дополнительной транспортной работы
- GPS-контроль и диспетчеризация
- усиление маршрутов удалённых микрорайонов

Общая стоимость сценария — 300 млн ₽.

## KPI

- 12 новых автобусов
- не менее 598 тыс. дополнительных автобусо-км
- выполнение не менее 96% плановых рейсов
- сохранение дефицита бюджета на уровне не выше 3,093 млрд ₽

## Методы

- анализ маршрутной сети
- анализ муниципального бюджета
- SWOT-анализ
- анализ стейкхолдеров
- бюджетное моделирование
- разработка KPI
